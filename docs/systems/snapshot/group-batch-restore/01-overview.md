# 背景与目标

[← 返回索引](../GROUP_BATCH_RESTORE.md)

> 版本：v1.0 · 日期：2026-06-17 · 状态：待评审

---

## 1.1 背景

当前存档 Tab（`LauncherFragment`）的分组卡片已支持 **全部归档**（`GroupBatchArchiver.archiveAllApps`），但 **没有对应的批量恢复** 入口。README 虽描述「按组批量操作快照和恢复」，用户实际只能：

1. 逐应用展开快照列表
2. 手动选择某个 `ArchiveItem` 恢复

典型痛点：

| 场景 | 现状 | 期望 |
|------|------|------|
| 刷机 / 清数据后补装一组应用 | 逐个找未安装应用再恢复 | 一键恢复组内 **未安装** 的应用 |
| 整组回滚到备份状态 | 逐个应用恢复最新快照 | 一键 **全部** 恢复 |
| 上次批量恢复后又做了新备份 | 无法区分哪些 app 需要再恢复 | 只恢复 **自上次恢复以来有更新** 的应用 |
| 组内应用普遍保留多份快照 | 只能逐个点选 | 批量统一选 **最新 / 最旧 / 与上次相同** |

时间线 Tab 已实现跨组批量恢复（`TimelineBatchOperator`），但它是 **按时间区域 + 多选** 定范围，无法替代组内的 **安装状态 / 增量恢复** 语义。

## 1.2 目标

1. 在分组卡片上提供 **批量恢复** 入口，与 **全部归档** 形成对称能力
2. 恢复前通过 **配置对话框** 让用户选择：
   - **恢复范围**：未安装 / 全部 / 自上次恢复以来
   - **快照选择**：最新 / 最旧 / 与上次恢复相同
3. 实时预览 **将恢复的应用数量**，并提示破坏性操作（覆盖已安装应用数据）
4. **调整组头布局**：合并批量操作为 `btn_batch` 菜单入口；保持标题与工具栏单行，按钮 36dp、标题 17sp
5. 执行过程使用 **串行恢复 + 统一进度对话框**，支持取消与成功/失败汇总
6. 持久化 **恢复记录**（`RestoreRecord`），支撑「自上次恢复以来」范围与「与上次相同」策略

## 1.3 非目标（首版不做）

- 批量 **高级恢复**（选择 data / apk / obb 等子集）—— 保留单应用入口
- 批量恢复时 **逐应用指定不同快照** —— 批量语义是统一策略
- **并行恢复** 多个应用 —— root IO 密集，串行更稳定
- 恢复完成后 **自动启动** 全部应用
- 跨分组批量恢复 —— 由时间线 Tab 负责
- 按日历日期手动选择时间范围 —— 由时间线 Tab 负责

## 1.4 已定设计决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 恢复语义 | 每个应用仅恢复 **一个** 快照 | 与时间线一致；恢复是「回到某个版本」 |
| 范围过滤 | 仅纳入 **有 ≥1 快照** 的应用 | 无快照则无可恢复内容 |
| 「自上次恢复以来」 | 从未恢复过 **或** 最新快照 `makeTime` > 上次恢复的 `archiveMakeTime` | 语义为增量恢复，非按日历筛 archive |
| 恢复记录粒度 | 按 `(groupId, packageName, userId)` 存储 | 与 `TimelineEntryKey` 对齐，支持多用户 |
| 恢复记录写入 | 单应用恢复成功 **和** 批量恢复每项成功均写入 | 避免单条/批量混用时范围判断不一致 |
| 组头入口 | **批量操作菜单**（归档 + 恢复），不新增独立恢复按钮 | 避免 6 个独立大按钮挤占标题区；单行 + 36dp 折中 |
| 执行 API | `ArchiveRestorer.restoreArchiveSuspend` | 已有无 UI 挂起版本，适合批量 |
| 进度 UI | `GroupItemsProgressDialog`，不逐条弹 `ItemProgressDialog` | 与 `GroupBatchArchiver` / `TimelineBatchOperator` 一致 |
| 批量互斥 | `SnapshotViewModel.isBatchRunning`，存档 / 时间线 Tab 共用 | 避免跨 Tab 并行 root IO；见 [附录 §A.5](../07-appendix.md#a5-全局批量互斥snapshotviewmodel) |
| 失败策略 | 单项失败 **继续下一项**，结束后汇总 | 与现有批量操作一致 |
| 锁定快照 | **不阻止** 恢复 | 锁定仅影响删除，现有行为不变 |
