# 国际化 (i18n)

> 资源路径：`app/src/main/res/values*/strings.xml`

## 支持语言

| Locale | 目录 | 说明 |
|--------|------|------|
| 默认 (fallback) | `values/strings.xml` | 简体中文 |
| `zh-CN` | `values-zh-rCN/strings.xml` | 显式简体中文（与默认内容一致） |
| `en` | `values-en/strings.xml` | 英文 |

系统语言为 **en** 时使用 `values-en`；**zh-CN** / **zh** 使用中文；其余 locale 回退至 `values/`。

## 约定

1. **用户可见文案** — Toast、对话框、菜单、Toolbar 标题、布局 `android:text` / `contentDescription` 均使用 `@string/` 或 `getString(R.string.*)`，禁止在 Kotlin/XML 中硬编码。
2. **键名** — `snake_case`，按功能前缀分组，例如 `group_batch_restore_*`、`provider_check_*`、`timeline_*`。
3. **格式化** — 占位符用 `%s`、`%d`、`%1$s`；数量相关文案优先使用 `plurals`。
4. **同步更新** — 新增或修改字符串时，三份 locale 文件必须保持 key 一一对应。
5. **不资源化** — `Log.*` 调试日志、`tools:text` 设计预览占位、包名/路径等技术常量；`provider` 模块无 UI 层，技术异常由 app 以原始文本展示。

## 覆盖范围

当前约 **320** 条字符串，已覆盖 `app` 模块全部界面，包括但不限于：

- 主界面权限检查、底栏 Tab、可折叠搜索
- 存档 Tab：分组列表、快照菜单、批量归档/恢复、进度对话框
- 应用/分组配置：排除规则、额外项、文件选择器、保留策略
- 时间线 Tab：筛选、多选、批量操作
- 应用 Tab：用户 Tab、系统/用户筛选、标签 Chip
- 设置、忽略应用、关于

## 贡献检查清单

- [ ] 三份 `strings.xml` 均已添加/更新对应 key
- [ ] Kotlin 中用户消息使用 `getString()` / `resources.getString()`
- [ ] 布局 XML 使用 `@string/`，无障碍 `contentDescription` 已资源化
- [ ] 含动态内容的文案使用格式化参数而非字符串拼接
- [ ] `./gradlew :app:assembleDebug` 构建通过
